# Phase 4 实现与评估

需求：[TK-44](https://app.notion.com/p/40a1a252e211812f823de2aa15c90bdb)。调研日期：2026-10-31。

## 技术路径

| 方向 | 比较 | 本次选择 |
| --- | --- | --- |
| 截图识别 | [screenshot-to-code](https://github.com/abi/screenshot-to-code) 使用视觉模型生成前端代码，仓库为 MIT；[PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR) 提供 OCR 与版面分析，代码为 Apache-2.0，适合自部署，但需要额外推理服务及布局映射 | 直接通过现有 AI SDK 向配置的视觉模型提交 PNG，结构化输出 Layout Tree 与节点置信度；不引入独立 OCR 部署。后续可用 OCR 校正识别文字 |
| 图片生成与编辑 | [Images API](https://developers.openai.com/api/docs/guides/image-generation) 支持生成、参考图与蒙版编辑；[ComfyUI](https://github.com/Comfy-Org/ComfyUI) 支持本地工作流，部署需算力，代码及所选模型权重的许可需分别核对 | `ImageProvider` 为独立接口，首个实现调用服务端固定的兼容 Images API 端点。要求返回 PNG 字节；拒绝模型返回的远程图片 URL，不自动下载未知地址 |
| 代码导出 | 布局树比截图直接生成字符串更便于保留层级与 Token；框架专属生成器会增加耦合 | `CodeAdapter` 注册表。React/CSS 产出每容器独立函数组件；HTML/CSS 为无需构建工具的对照产物。两者复用布局及资源映射，不执行产物 |

模型服务的商业条款与开源项目的代码许可是两回事。托管服务按供应商账单结算；自部署需计入 GPU、运维及模型权重许可。接口兼容不表示模型一定支持视觉、结构化输出、参考图、蒙版、质量或请求尺寸，需分别验收。

## 协议与边界

- `/api/agent/advanced` 复用同源检查、登录 Cookie、文件权限、当前编辑器会话、并发限制与有界请求体。
- 图片输入：`{data,width,height}`，data 为纯 PNG base64，服务端核对 PNG 文件头与尺寸，禁止 SVG 和任意图片 URL。
- 视觉结果：`{layout,confidence:[{key,score,note}],metadata}`。每个布局节点对应一个置信度，score 为模型自评，不能当作校准概率。根尺寸须匹配输入，结果必须含可编辑文字或形状。
- 用户可以修正布局 JSON。`prepare-layout` 只编译为白名单操作；随后复用五分钟有效的计划、用户确认、最多十步分批执行、原生撤销与回读检查。
- 图片生成：提示词、尺寸/比例、质量、候选数量、可选参考图/蒙版。预览保存于服务内存，最多十六张，并绑定账号、编辑器、文件和页面。只通过返回的候选 ID 选择插入。
- `create_image` 在确认后上传媒体并创建矩形；`set_image` 仅替换图片矩形的填充，核对上传前后的范围与对象快照，并验证对象身份、几何和图片 ID。上传成功但后续失败时可能留下未使用媒体，画布不会自动回滚。
- 代码下载仅含文本，面板不使用 iframe 或 eval 执行代码。自由定位区域保持局部绝对坐标并提示；明确 row/column 约束输出 Flex。复杂图标、缺失组件实现、业务逻辑与响应式断点不作推测。
- 完整选区可在大页面中单独导出；选区自身截断则拒绝。未提供图片字节的导出使用 `assets.json` 中的同源资源路径，离线项目需自行下载并替换。原图参考编辑当前需要上传原图。

## 成本、耗时与质量记录

截图结果返回模型名称、token usage、durationMs、质量提示与许可说明；图片结果返回模型名称、提示词、尺寸、质量、durationMs、供应商 usage 与 `AI_IMAGE_LICENSE`。本 PoC 不计算金额，明确显示以供应商账单为准。可保存面板中的元数据用于成本对比。

本次自动化测试以 SDK 模型替身与图片服务替身验证协议、转译和失败处理。它们的毫秒耗时不代表模型性能。当前没有配置图片生成模型或密钥，未进行付费图片调用，因此实际图片质量、成本与响应时间尚待实测；真实截图 OCR 准确率与结构还原度也不能由替身测试推断。

## 验收与继续投入的依据

1. 用同一组有权使用的真实网页截图和设计稿，分别记录原图、模型与版本、识别结果、人工修正后的布局及执行回读。保留每张图的来源和授权信息。
2. 文字指标：人工标注文字，与识别结果计算字符错误率（插入、删除、替换数 / 标注字符数），中文与英文分别记录。
3. 结构指标：标注区域及父子关系，记录区域召回率、父子关系正确率、可编辑文字比例与占位节点数量；几何指标可使用同尺寸矩形 IoU。不要用模型自评置信度替代人工标注。
4. 图片指标：同提示词、比例、质量各生成至少三轮，记录失败率、供应商计费、端到端延迟、人工质量评分、参考图一致性与蒙版外区域变化。确认替换后对象 ID、关系和几何不变。
5. 代码指标：下载 React/CSS 产物放入已有 React 项目编译；检查 Token、组件层级、文字与图片路径。HTML/CSS 用同一布局对照检查。两个产物都不包含业务交互实现。
6. 根据实际 OCR、结构指标、人工修正时间、每次有效产物费用及许可决定下一阶段；本次没有实测依据来宣称生产可用或建议固定供应商。

自动化覆盖见 `AdvancedDesign.test.ts`、`DesignEditor.test.ts`、`PenpotSession.test.ts` 与前端 `workspace_ai_test.cljs`。不把人工模型质量评估标记为已通过。

## 本地验证结果

- Agent 32 项、图片 HTTP 适配器 2 项、插件 61 项、MCP Server 88 项测试通过。
- 前端相关 11 项测试、41 个断言通过；AI 面板独立编译 676 个文件，0 警告。
- 相关 TypeScript 检查、ClojureScript 静态检查、前端格式检查与 SCSS 编译通过。完整测试编译存在其他测试中的类型推断警告。
- 验证在限制 3 GB 内存的独立容器中进行，原服务与数据卷只读挂载。用户主动关闭的 Penpot 服务保持关闭。
- 现有 OpenCode Go 接口的模型发现请求分别返回 403、404；加入官方要求的客户端与会话请求头后仍返回 404。[官方模型清单](https://opencode.ai/v2/docs/console/go/)未列出图片生成模型。本次无法确认可用的生图模型，未写入猜测的模型名，也未把模拟图片当作真实生成结果。
