# 原生 AI 页面生成

在 Penpot 的 AI 面板描述页面目标、使用角色、主要区域和风格。助手先提交页面规划与布局树；缺少关键业务信息时先提问。核对方案的区域层级、尺寸、操作范围、临时样式与规则检查结果，再点击「确认执行」。

示例需求：

> 为设备操作员生成 1200 × 800 的工业控制台。包含侧栏、页面标题、在线设备与告警指标卡、设备列表和告警区域。指标与列表使用明确标注的示例数据。优先使用当前文件的品牌颜色和文本样式，提供侧栏与顶栏两个布局方案。

生成后选中目标区域，可以继续要求「将标题改为设备运行总览」或「把这个区域移到指定位置」。局部修改使用现有对象 ID。当前快照未覆盖目标区域时，需要先选中该区域。服务仅提供当前账号、编辑器、文件与页面最近三次执行的摘要；不依赖完整聊天记录定位对象。

## 执行与恢复

- 每个方案最多 120 个布局节点、六层容器；每轮最多两个方案。
- `LayoutTree.ts` 定义独立 IR；`LayoutPlanner` 求解相对坐标、行列方向、内边距、间距及交叉方向对齐，转换为白名单 Design Tools。
- 支持容器、文本、矩形、图片占位与当前文件组件实例。组件实例保留原样式。当前文件的纯色和文本样式可通过资产引用复用；未匹配部分明确列为临时样式，不新建近似资产。
- 每次 MCP 调用最多十步，每批建立独立的原生撤销记录。执行前及批次间重新检查文件、页面、选区、已有对象与资产。计划五分钟过期。
- 点击「取消后续生成」可停止后续步骤。已完成内容保留，可按批撤销；失败步骤可能已修改画布，界面显示相关对象。失联后不重试，并保留已收到的批次结果。
- 页面默认放在现有内容右侧，保留已有设计。工具不提供整页删除或任意 JavaScript 执行。
- 每步与每批末尾回读实际对象，核对尺寸、位置、层级与样式。规则检查列出越界、矩形重叠、偏离确认位置及样式不符，可定位相关图层。矩形重叠可能为有意叠放，需人工判断。

## 当前边界

布局约束在生成时求解，产物是固定尺寸的可编辑元素，尚不建立随容器缩放自动重排的响应式规则。交互清单只用于视觉规划，不创建真实业务逻辑。资产读取有数量上限，并显示截断提示。

## Phase 4 高级设计

在 AI 面板展开「高级设计：截图、图片与代码」。三个入口独立使用，写入继续经过原有确认执行与回读验证。

- 截图：上传 PNG，选择支持视觉输入及结构化输出的模型，点击「识别截图结构」。查看逐节点置信度，修正 Layout Tree JSON 的文字、层级、间距和样式，再点击「预览可编辑 UI 操作」并确认。复杂图标与图片会标为占位；置信度为模型自评。
- 图片：填写提示词，选择尺寸、质量与候选数量。可上传风格参考图；同尺寸透明 PNG 蒙版用于局部编辑，透明区域待重绘。生成后选择候选，预览插入或替换选中的图片矩形，再确认执行。替换保留对象 ID、父子关系、位置与尺寸。编辑已有图片时，将原图作为参考图上传。
- 代码：选择 React 组件/CSS 或 HTML/CSS，导出当前选区、完整页面或修正后的布局树。在面板逐文件预览和下载。容器映射为命名区块或独立 React 函数组件，行列映射 Flex，颜色与文本 Token 映射 CSS 变量。图片资源来源记录在 `assets.json`；部署前下载并替换资源路径。组件实例保留引用标记，需由项目组件替换。

输入与生成图片限 PNG、约 2 MB、宽高不超过 4096。预览有效期五分钟。图片模型通过 `.env.example` 中的 `AI_IMAGE_*` 服务端变量配置；默认关闭，不向浏览器发送密钥。修改后需重启 Agent 服务、重建 MCP common/server/plugin 并刷新编辑器。反向代理的 `/api/agent/` 需允许至少 6 MB 请求体与 180 秒响应时间。

对话中的参考图生成最多等待四分钟。支持推理强度设置的模型可配置 `AI_REASONING_EFFORT=low`，缩短等待；未配置时保留模型默认值。密集表格与日志先生成主体和少量示例行，再按需补充细节。工具参数校验失败时，模型可在同一轮数上限内修正；通过校验后才生成待确认计划。

调研、适配器选择、评估方法和未实测项目见 [PHASE4.md](PHASE4.md)。

## 验证

`LayoutPlanner.test.ts` 包含固定仪表盘、引用校验、坐标求解、资产匹配、越界及重叠检查。Agent 测试覆盖澄清与多方案预览。插件测试覆盖真实操作计划的分批创建、取消、批次间变化、资产引用和最终回读；前端测试通过实际 Plugin API 验证嵌套画板与文字位置及原生撤销。

手动验收时，先在空文件确认生成，再在含已有设计的页面重复；检查已有内容保留。分别尝试选中区域后修改标题、生成中取消、确认前改动目标对象，以及生成后从问题清单定位图层。
